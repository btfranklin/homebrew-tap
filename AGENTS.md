# Agent guide

This repository holds Homebrew formulas for B.T. Franklin.

- Work on `main`. Create a branch or pull request only if B.T. asks.
- Keep formula build and test rules in `Formula/`.
- Write technical text in ASD-STE100 Simplified Technical English.
- Keep user setup in `README.md` and maintainer steps in
  `docs/maintaining.md`.
- Use only verified source URLs, licenses, and release data.
- Do not add a stable URL or bottle until its release artifact is published.
- Do not commit, publish, or create a remote unless B.T. asks.

Read [maintaining the tap](docs/maintaining.md) for validation and release
steps.
